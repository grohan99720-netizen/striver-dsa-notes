# striver-dsa-notes

Java notes and revision points following the [official Striver A2Z DSA Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/).

## Notes

### Basic Maths
- [Basic Maths](Basic-Maths/basic-maths.md): prime checking, counting primes, GCD, and LCM.

### Arrays
- [Arrays — Basic Problems](Arrays/array-basics.md): divisors, array sum, running sum, counting odd numbers, and checking sorted order.
- [Arrays — More Problems](Arrays/array-more-problems.md): reverse an array, second-highest occurring element, and sum of highest and lowest frequency.

### Basic Strings
- [Valid Anagram](Strings/basic-strings.md): LeetCode 242, frequency-counting approach.

### Revision
- [Patterns and Complexity](Patterns/patterns-and-complexity.md): reusable algorithms, common DSA patterns, and general time and space complexity reference.

## How to use these notes

- Follow the problem order from the official Striver A2Z DSA Sheet.
- Read the problem and try it before referring to the approach or Java code.
- Problem notes distinguish between topics discussed and solutions that have been fully tested.
- Use the patterns file for quick revision; keep problem-specific details in the topic files.
