# striver-dsa-notes

Java notes and revision points following the Striver A2Z DSA Sheet.

## Notes

- [Arrays — Basic Problems](Arrays/array-basics.md): divisors, array sum, running sum, counting odd numbers, and checking sorted order.

## How to use these notes

- Follow the problem order from the [official Striver A2Z DSA Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/).
- Read the intuition and try the problem before referring to the Java solution.
- Use the revision points at the end of each topic to review patterns and mistakes.
